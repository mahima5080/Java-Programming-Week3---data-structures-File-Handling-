# Java Programming — Week 3: Data Structures & File Handling

## 📌 Topics Covered
* Java Collections Framework (`ArrayList`, `HashMap`, `HashSet`)
* Sorting and Searching Algorithms
* File I/O using `FileReader` and `FileWriter`
* Exception Handling (`try`, `catch`, `finally`, `throw`, `throws`)

---

## 📁 Repository Contents
1. `StudentMarksRecord.java`: Analyzes student marks stored in an `ArrayList` to calculate highest, lowest, and class average scores.
2. `WordFrequencyCounter.java`: Reads text files, counts word frequencies using `HashMap`, and outputs clean reports using `FileReader` and `FileWriter`.
3. `EmployeeManagementSystem.java`: **Mini Project** — Console app utilizing `ArrayList`, persistent `.txt` file storage, and exception handling for input validation.

---

## 🚀 How to Run
```bash
javac StudentMarksRecord.java
java StudentMarksRecord

javac WordFrequencyCounter.java
java WordFrequencyCounter

javac EmployeeManagementSystem.java
java EmployeeManagementSystem
